## Kometa 1.12.0

**Aplikácia je úplne samostatná – a Kometa pre Python sa lúči.**

- **Deno doinštaluje Kometa sama.** YouTube dnes cez yt-dlp funguje len s JavaScriptom (Deno).
  Doteraz ho aplikácia používala len vtedy, keď ho do systému nainštaloval `Instalacia.bat`
  z Kometa pre Python – teraz si stiahne vlastné z oficiálnych vydaní, overí kontrolný súčet
  a odovzdá ho yt-dlp priamo.
- **Vlastný yt-dlp, vždy aktuálny.** Kometa si chvíľu po prvom spustení doinštaluje vlastnú kópiu
  (nepoužíva tú zo systému) a raz denne skontroluje, či nie je novšia – YouTube sa mení často
  a starý yt-dlp prestane stačiť. Deno sa obnoví pri novej hlavnej verzii.
- V *Nastaveniach → Pomocníci* vidno yt-dlp (s verziou), Deno a FFmpeg.
- **Prechod z Kometa pre Python:** aplikácia pri prvom spustení prevezme nedokončené sťahovania
  z Kometa pre Python. Nastavenia a účty sú spoločné.
- **Kometa pre Python končí:** hore v okne ukáže pás **Prejsť na aplikáciu** – stiahne inštalačku
  aplikácie, overí ju súčtom SHA-256 (aj odtlačkom GitHubu) a spustí ju. Toto je posledná verzia
  Kometa pre Python; Kometa 2.0 bude už len aplikácia.

Aplikácia nie je digitálne podpísaná:
- Windows ukáže upozornenie – klikni **Ďalšie informácie → Spustiť aj tak**.
- V macOS ju prvýkrát otvor pravým tlačidlom → **Otvoriť**.

Kontrolné súčty sú v `SHA256SUMS.txt`.
