## Kometa 1.5.1

**Opravy**

- **Priečinok na ukladanie podľa systému.** Kometa ukladá do systémového priečinka Videá – aj keď je
  presmerovaný na iný disk (napr. `D:\DOKUMENTY\Videos`) alebo v Linuxe preložený („Videá“). V macOS
  do priečinka Filmy (Movies). Ak mala Kometa uložený pôvodný predvolený priečinok, ktorý systém
  medzitým presmeroval, opraví ho sama. Skôr stiahnuté súbory ostanú tam, kde boli. Priečinok, ktorý
  si si vybral sám, sa nemení. Platí pre aplikáciu aj Kometu pre Python.
- **Ikona priečinka pri stiahnutom súbore** otvorí správny priečinok a súbor v ňom označí. Doteraz sa
  pri názvoch s medzerami otvoril iný priečinok (Dokumenty).

**Zmena**

- Samostatný program pre príkazový riadok má v názve `noGUI`
  (napr. `kometa-1.5.1-windows-x64-noGUI.exe`) – nemá vlastné okno a dvojklikom sa nič neotvorí.
  Na bežné používanie je inštalátor `Kometa-1.5.1-windows-x64-setup.exe`.

### Inštalácia

| systém | súbor |
|---|---|
| Windows 10/11 | `Kometa-1.5.1-windows-x64-setup.exe` |
| macOS 11+ | `Kometa-1.5.1-macos.dmg` |
| Linux | `Kometa-1.5.1-linux-x86_64.AppImage` alebo `Kometa-1.5.1-linux-amd64.deb` |
| príkazový riadok, bez okna | `kometa-1.5.1-windows-x64-noGUI.exe`, `kometa-1.5.1-macos-noGUI`, `kometa-1.5.1-linux-x86_64-noGUI` |
| Kometa pre Python | `Kometa-1.5.1.zip` → `Instalacia.bat` |

Aplikácia nie je digitálne podpísaná: vo Windows klikni **Ďalšie informácie → Spustiť aj tak**,
v macOS ju prvýkrát otvor pravým tlačidlom → **Otvoriť**. Kontrolné súčty sú v `SHA256SUMS.txt`.
