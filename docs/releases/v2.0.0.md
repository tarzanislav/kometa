## Kometa 2.0.0

**Kometa je jedna aplikácia – bez Pythonu.**

- **Len aplikácia.** Kometa pre Python sa ďalej nevydáva; vo vydaní už nie je ZIP
  s `Instalacia.bat`. Aplikácia vie všetko, čo ona, a viac: vlastné sťahovanie a spájanie
  MKV/MP4 bez FFmpeg, strážcu schránky, kurzy po prihlásení, automatické aktualizácie.
- **Prechod z Kometa pre Python:** nainštaluj aplikáciu (v Kometa pre Python 1.12 tlačidlom
  **Prejsť na aplikáciu**). Prevezme nastavenia a účty a pri prvom spustení aj nedokončené
  sťahovania. Python, FFmpeg ani Deno z `Instalacia.bat` netreba – pomocníkov si aplikácia
  stiahne sama. Priečinok so starou Kometou potom môžeš zmazať.
- **Jeden zdroj verzie** pre aplikáciu, program bez okna aj postup vydania; rozhranie je vložené
  priamo v jadre.
- Pri vývoji rozhrania (`npm run dev`) sa volania posielajú jadru spustenému príkazom
  `kometa okno --port 8765 --bez-okna`.

Ďalej: vlastné sťahovanie z YouTube (yt-dlp ostane ako záloha), titulky z Vimea a Android.

Aplikácia nie je digitálne podpísaná:
- Windows ukáže upozornenie – klikni **Ďalšie informácie → Spustiť aj tak**.
- V macOS ju prvýkrát otvor pravým tlačidlom → **Otvoriť**.

Kontrolné súčty sú v `SHA256SUMS.txt`.
